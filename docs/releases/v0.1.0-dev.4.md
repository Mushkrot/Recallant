# Recallant v0.1.0-dev.4

`v0.1.0-dev.4` is a development prerelease that makes remote connection approval easier to follow.
When device trust expires, onboarding explains why confirmation is needed and offers to open the
approval page. After approval, the command continues automatically. Interactive approval waits up
to five minutes; unfinished approval, cancellation and expired pages show a useful next step.

Non-interactive runs never open a browser. Unfinished connections retain unsuccessful exit status
and return structured approval guidance. Device trust duration and project credential isolation
remain unchanged. The release also includes configured public-server discovery and dependency fixes.

Install or update the tagged release:

```bash
curl -fsSL https://raw.githubusercontent.com/Mushkrot/Recallant/v0.1.0-dev.4/scripts/install-recallant-bootstrap.sh \
  | bash -s -- --ref v0.1.0-dev.4
recallant --version
recallant onboard .
```

## Rollback

Keep the previous installation and its existing configuration until the new client is verified.
To return to the preceding tagged release, run the trusted installer with `--ref v0.1.0-dev.3`.
Do not remove the shared profile, trusted-device key or project credential store.
