# Recallant v0.1.0-dev.0

`v0.1.0-dev.0` is Recallant's first installable development prerelease. It packages the current
Codex-first governed-memory workflow as a reviewable proof of engineering work; it is not a stable
production support promise.

## What ships

- A TypeScript monorepo with CLI, MCP server, protected Workbench, PostgreSQL/pgvector storage,
  provenance, review, audit, redaction, backup, recovery, and rollback controls.
- The universal `recallant onboard <project>` beginner path for a configured Recallant host.
- Automatic native Codex capture plus governed session start, context, checkpoint, closeout, and
  next-session recall evidence.
- Scoped remote MCP, public-safe synthetic Workbench screenshots, deterministic product gates, and
  browser acceptance coverage.

The [README](../../README.md) contains the architecture summary and three synthetic-data Workbench
screenshots.

## Pinned self-host install

Install this exact source release rather than a moving development branch:

```bash
curl -fsSL https://raw.githubusercontent.com/Mushkrot/Recallant/v0.1.0-dev.0/scripts/install-recallant-bootstrap.sh \
  | bash -s -- --ref v0.1.0-dev.0
```

Then verify the release identity:

```bash
recallant --version
# recallant 0.1.0-dev.0+<release-sha>
```

A tagged installation stays pinned to `v0.1.0-dev.0`. Interactive onboarding does not silently
replace it with the `main` development channel. Switching channels is an explicit reinstall using
the bootstrap script and `--ref main`.

## Verification and security posture

The release gate covers format, lint, build, production and full dependency audits, deterministic
product tests, clean-host and pinned-ref installation, onboarding, public readiness/security,
CodeQL, Playwright, remote rehearsal regressions, and marker-based install rollback. Recallant keeps
Workbench, administration, MCP administration, backup, database, and raw-artifact surfaces private
or authenticated by default.

## Known limitations

- Native automatic capture is Codex-first. Claude Code, Cursor, and Windsurf can use configured MCP
  access, but that does not prove native capture parity.
- A real Codex-to-Claude Code-to-Codex continuity pass remains a future milestone.
- General human document memory, folder crawling, and PDF/DOCX ingestion are not shipped.
- npm package publication and stable `1.0` compatibility guarantees are out of scope.
- Operators remain responsible for access policy, backups, model availability, and production
  capacity.

## Upgrade and Rollback

Use a newer reviewed tag with the same pinned install form when one is published. To leave the
prerelease channel for current development deliberately, rerun the bootstrap with `--ref main`.

For removal or a failed disposable install, use `scripts/rollback-recallant-install.sh` in dry-run
mode first. Confirm only the marker-backed Recallant paths shown by the preview; the rollback helper
refuses unmarked data directories.
