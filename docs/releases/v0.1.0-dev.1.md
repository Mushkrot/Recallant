# Recallant v0.1.0-dev.1

`v0.1.0-dev.1` is a reproducible development prerelease of Recallant. It packages the current
Codex-first governed-memory workflow with the CLI, MCP server, protected Workbench, PostgreSQL/
pgvector storage, provenance, review, audit, redaction, recovery, and rollback controls.

## Install this release

```bash
curl -fsSL https://raw.githubusercontent.com/Mushkrot/Recallant/v0.1.0-dev.1/scripts/install-recallant-bootstrap.sh \
  | bash -s -- --ref v0.1.0-dev.1
```

Then verify the pinned identity:

```bash
recallant --version
# recallant 0.1.0-dev.1+<release-sha>
```

The universal beginner path is `recallant onboard <project>`. Automatic native capture is
Codex-first; other clients can use configured MCP access. Workbench, administration, MCP
administration, backup, database, and raw-artifact surfaces remain private or authenticated by
default.

## Verification

The release gates cover format, lint, build, dependency audits, deterministic product tests,
clean-host and pinned-ref installation, onboarding, public readiness/security, CodeQL, Playwright,
remote integration rehearsals, and install rollback.

## Known limitations

- Native capture parity for Claude Code, Cursor, and Windsurf is not promised.
- General document crawling and PDF/DOCX ingestion are not included.
- npm package publication and stable `1.0` compatibility guarantees are out of scope.
- Operators remain responsible for access policy, backups, model availability, and capacity.

## Upgrade and Rollback

Use the same pinned install form with a newer reviewed tag when available. For removal or a failed
disposable install, run `scripts/rollback-recallant-install.sh` in dry-run mode first and confirm
only marker-backed Recallant paths shown by the preview.
